# Bhramastra - Production Build

This is the production-ready build of the Bhramastra motivational platform.

## 🚀 Quick Start

### Option 1: Using Node.js (Recommended)
```bash
cd build
npm install
npm start
```

### Option 2: Using Python
```bash
cd build
python -m http.server 3000
```

### Option 3: Using PHP
```bash
cd build
php -S localhost:3000
```

## 📁 Build Contents

- `index.html` - Optimized HTML with SEO and performance enhancements
- `assets/` - All JavaScript, CSS, and image assets
- `favicon.ico` - Website favicon
- `robots.txt` - SEO robots configuration
- `sitemap.xml` - SEO sitemap
- `sw.js` - Service Worker for caching
- `.htaccess` - Apache server configuration
- `vercel.json` - Vercel deployment configuration
- `serve.json` - Serve package configuration

## 🌐 Deployment Options

### Vercel
```bash
vercel --prod
```

### Netlify
```bash
netlify deploy --prod --dir .
```

### Apache/Nginx
Upload all files to your web server root directory.

### GitHub Pages
1. Push this build folder to a `gh-pages` branch
2. Enable GitHub Pages in repository settings
